# EDA-LLM Benchmark: Hard EDA Task for Code-Executing LLMs

> Work in progress. Recruitment task for deepsense.ai (AI Benchmark & Datasets Engineer).

**Goal:** an exploratory data analysis task on a manufacturing dataset (target **Y = batch defect rate**) that a code-executing LLM can solve only partially, with a deterministic partial-credit score in [0, 1].

## Deliverables
| Deliverable | Location |
|---|---|
| Dataset | `data/` (generated by `edabench.generate`) |
| Task prompt | `task/prompt.md` |
| Model output | `outputs/` |
| Measure definition | `edabench/scorer.py` + `task/measure.md` |

## Pipeline
`generate -> prompt -> run (model + sandboxed code execution) -> log -> score -> report`, configured by `configs/benchmark.yaml`.

## Quickstart
```bash
make install
make test
```
