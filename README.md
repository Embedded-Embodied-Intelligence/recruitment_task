# EDA-LLM Benchmark: Hard EDA Task for Code-Executing LLMs

> Work in progress. Recruitment task for deepsense.ai (AI Benchmark & Datasets Engineer).

**Goal:** an exploratory data analysis task on a manufacturing dataset (target **Y = batch defect rate**) that a code-executing LLM can solve only partially, with a deterministic partial-credit score in [0, 1].

## Deliverables
| Deliverable | Location |
|---|---|
| Dataset | `data/` (generated by `edabench.generate`) |
| Task prompt | `task/prompt.md` (design notes: `docs/prompt_design.md`) |
| Model output | `outputs/` |
| Measure definition | `docs/measure.md` (implementation `edabench/scorer.py`) |

## Pipeline
`generate -> prompt -> run (model + sandboxed code execution) -> log -> score -> report`, configured by `configs/benchmark.yaml`.

## Quickstart
```bash
make install
make test          # generator reproducibility, trap injection, planted effects detectable
make data          # data/batches.csv, data/suppliers.csv + eval/ground_truth.json
make data-notraps  # ablation variant without traps
make reference     # re-run the expert notebook (scores 0.995)
python -m edabench.scorer reference/reference_answer.json   # score any response
```

`eval/ground_truth.json` is the answer key. Only `data/` and `task/prompt.md` are given to the model.
