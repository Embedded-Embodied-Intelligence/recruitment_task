# EDA-LLM Benchmark: Hard EDA Task for Code-Executing LLMs

> Recruitment task for deepsense.ai (AI Benchmark & Datasets Engineer). **Start with [SUBMISSION.md](SUBMISSION.md)**: deliverables, results, limitations.

**Goal:** an exploratory data analysis task on a manufacturing dataset (target **Y = batch defect rate**) that a code-executing LLM can solve only partially, with a deterministic partial-credit score in [0, 1].

## Deliverables
| Deliverable | Location |
|---|---|
| Dataset | `data/` (generated by `edabench.generate`) |
| Task prompt | `task/prompt.md` (design notes: `docs/prompt_design.md`) |
| Model output | `outputs/runs/v5_seed42/` (10 harness runs and report; primary example `claude-sonnet/full/run_01/`), v4 runs in `outputs/runs/v4_seed42/`, pilots in the Claude app in `outputs/pilot_*` |
| Measure definition | `docs/measure.md` (implementation `edabench/scorer.py`) |

## Pipeline
`generate -> prompt -> run (model + sandboxed code execution) -> log -> score -> report`, configured by `configs/benchmark.yaml`.

## Quickstart
```bash
make install       # includes the harness extra (openai, jupyter_client, ipykernel)
make test          # generator reproducibility, trap injection, planted effects detectable
make data          # data/batches.csv, suppliers.csv, maintenance.csv + eval/ground_truth.json
make data-notraps  # ablation variant without traps
make reference     # re-run the expert notebook (scores 0.984 on v5)
python -m edabench.scorer reference/reference_answer.json   # score any response
```

`eval/ground_truth.json` is the answer key. Only `data/` and `task/prompt.md` are given to the model.

## Running models (harness)
`edabench.runner` runs each model N times per prompt variant and scores every answer; `edabench.report` aggregates the runs. Claude models run through `claude -p` on a Pro login, free APIs (Gemini, Groq) through a tool-calling loop with a local Python sandbox. Details: `docs/harness.md`.

```bash
python -m edabench.runner --check claude-haiku     # verify isolation first
python -m edabench.runner --model claude-haiku claude-sonnet --variant full no_quality_hint --runs 5
python -m edabench.report outputs/runs/v5_seed42   # earlier: v4_seed42, v3_seed42
```
